# Rodillo 3D — simulador de recorridos GPX y entrenamientos por potencia

App web para rodillo smart: carga un track **GPX** (por ejemplo, exportado de Garmin), lo reconstruye en **3D** con relieve y foto satelital, y simula la pendiente cambiando la resistencia del rodillo. También corre **entrenamientos estructurados en modo ERG** (.json o .zwo de Zwift).

**Usala acá:** https://sebaaragon1977.github.io/planes-de-ciclismo-by-seba-aragon/

## Requisitos
- **Google Chrome o Edge** (Mac, Windows, Linux o Android). Safari, Firefox e iPhone no permiten Bluetooth web.
- Rodillo smart **Bluetooth FTMS** (Wahoo, Tacx, Elite, Saris, Zwift Hub…) o **ANT+ FE-C** con pendrive USB (por ejemplo, Bkool).
- Opcional: pulsómetro Bluetooth.

## Uso rápido
1. Cargá tus datos en el panel: peso, FTP y umbral de pulso.
2. **📂 Cargar GPX** o **🏋️ Cargar entrenamiento** (`demo_3x5_200W.json` es un ejemplo).
3. **🔗 Conectar rodillo** (primero prueba ANT+, después Bluetooth).
4. Pedaleá: arranca sola. Al terminar podés **exportar el TCX** y subirlo a Garmin Connect o Strava.
